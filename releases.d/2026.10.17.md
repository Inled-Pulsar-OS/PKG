## New: a release notes window after every update

- When an update finishes, Pulsar OS will automatically show a window with the
  release notes, rendered from Markdown and nicely formatted.
- The window is **offline**: the notes travel inside the `pulsaros-whatsnew`
  package, so they can be read even when there is no network at that moment.
- It includes a **full history** you can browse from the dropdown at the top,
  with all the previous versions.

## How it works

1. Every update is documented in a file inside the `releases.d/` directory of
   the packages repository.
2. The `pulsaros-whatsnew` package bundles those notes and is published along
   with the rest of the packages.
3. A `dpkg`/`libalpm` hook notifies the user session and the viewer opens once
   with the news.

> You can hide these automatic popups from the window menu, or browse the
> history whenever you like from "What's New in Pulsar OS".

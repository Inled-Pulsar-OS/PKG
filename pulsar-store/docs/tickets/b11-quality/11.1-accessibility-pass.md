# 11.1 Accessibility pass

- **Block:** B11 Quality
- **Size:** L (up to 1 week)
- **Depends on:** none
- **Labels:** `block:quality`, `size:L`

## Summary

Make the app usable without a mouse or sight.

## Acceptance criteria

- [ ] Every interactive widget has an accessible name and role.
- [ ] Full keyboard navigation; verified with Orca.
- [ ] Contrast checked in light, dark, and glass fallback.

## Definition of done

- [ ] Tests added or updated; `cargo test` passes
- [ ] `cargo clippy -- -D warnings` and `cargo fmt --check` pass
- [ ] No user-facing string bypasses the i18n helpers
- [ ] Docs updated; screenshot attached for UI changes

# 11.6 Require checksums for native package installs

- **Block:** B11 Quality
- **Size:** M (up to 3 days)
- **Depends on:** none
- **Labels:** `block:quality`, `size:M`, `security`

## Summary

Finding F1 in `docs/threat-model.md`. A tampered native package installs as root if a mirror lies and the catalog has no checksum.

## Acceptance criteria

- [ ] Native package installs fail when the catalog declares no `sha256`, unless the user turns the check off in settings.
- [ ] The catalog guide and schema document `sha256`.
- [ ] Tests cover missing, wrong, and correct checksums.

## Definition of done

- [ ] Tests added or updated; `cargo test` passes
- [ ] `cargo clippy -- -D warnings` and `cargo fmt --check` pass
- [ ] No user-facing string bypasses the i18n helpers
- [ ] Docs updated; screenshot attached for UI changes

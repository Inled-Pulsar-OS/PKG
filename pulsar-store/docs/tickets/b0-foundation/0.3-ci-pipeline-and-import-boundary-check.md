# 0.3 CI pipeline and import-boundary check

- **Block:** B0 Foundation and governance
- **Size:** M (up to 3 days)
- **Depends on:** 0.2
- **Labels:** `block:foundation`, `size:M`

## Summary

Automate build, test, lint, and enforce layer rules that a single crate cannot enforce by itself.

## Acceptance criteria

- [ ] GitHub Actions: build, `cargo test`, `cargo clippy -- -D warnings` (blocking), `cargo fmt --check`, `cargo deny check`.
- [ ] A script or test fails the build if `core` imports `ui`, `modules`, or `gtk`/`adw`, if `ui` imports `modules`, or if one module imports another.
- [ ] Cargo cache configured; runtime under 10 minutes.

## Definition of done

- [ ] Tests added or updated; `cargo test` passes
- [ ] `cargo clippy -- -D warnings` and `cargo fmt --check` pass
- [ ] No user-facing string bypasses the i18n helpers
- [ ] Docs updated; screenshot attached for UI changes

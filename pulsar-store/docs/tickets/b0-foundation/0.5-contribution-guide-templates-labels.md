# 0.5 Contribution guide, templates, labels

- **Block:** B0 Foundation and governance
- **Size:** S (up to 1 day)
- **Depends on:** none
- **Labels:** `block:foundation`, `size:S`

## Summary

Make the project easy to contribute to.

## Acceptance criteria

- [x] `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, issue and PR templates.
- [x] Conventional Commits documented; definition of done documented (tests, clippy, fmt, docs, screenshot for UI, no hard-coded user-facing strings).
- [x] Label set documented: `block:*`, `size:*`, `good-first-issue`.

## Definition of done

- [ ] Tests added or updated; `cargo test` passes
- [ ] `cargo clippy -- -D warnings` and `cargo fmt --check` pass
- [ ] No user-facing string bypasses the i18n helpers
- [ ] Docs updated; screenshot attached for UI changes

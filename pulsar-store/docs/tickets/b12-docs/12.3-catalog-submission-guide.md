# 12.3 Catalog submission guide

- **Block:** B12 Docs and community
- **Size:** S (up to 1 day)
- **Depends on:** 1.3
- **Labels:** `block:docs`, `size:S`

## Summary

Let publishers add apps.

## Acceptance criteria

- [ ] Guide covers schema fields, localization, images, and validation.

## Definition of done

- [ ] Tests added or updated; `cargo test` passes
- [ ] `cargo clippy -- -D warnings` and `cargo fmt --check` pass
- [ ] No user-facing string bypasses the i18n helpers
- [ ] Docs updated; screenshot attached for UI changes

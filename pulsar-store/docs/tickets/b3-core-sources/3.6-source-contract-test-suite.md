# 3.6 Source contract test suite

- **Block:** B3 core: package sources
- **Size:** M (up to 3 days)
- **Depends on:** 1.2
- **Labels:** `block:core-sources`, `size:M`

## Summary

A reusable test suite every `PackageSource` must pass.

## Acceptance criteria

- [ ] Tests cover install, uninstall, update, idempotency, cancellation, and error mapping, run against fakes.
- [ ] Adding a new source requires wiring it into this suite.
- [ ] Documented in the add-a-source tutorial (12.2).

## Definition of done

- [ ] Tests added or updated; `cargo test` passes
- [ ] `cargo clippy -- -D warnings` and `cargo fmt --check` pass
- [ ] No user-facing string bypasses the i18n helpers
- [ ] Docs updated; screenshot attached for UI changes

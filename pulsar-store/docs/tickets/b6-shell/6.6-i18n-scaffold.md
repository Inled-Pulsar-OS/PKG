# 6.6 i18n scaffold

- **Block:** B6 Application shell
- **Size:** M (up to 3 days)
- **Depends on:** 0.2
- **Labels:** `block:shell`, `size:M`

## Summary

Make every user-facing string translatable from the first screen.

## Acceptance criteria

- [x] gettext set up with domain `pulsar-store`; `.pot` extraction script and `assets/locale/` tree.
- [x] Helper macros for singular, plural, and context strings.
- [x] CI fails on a user-facing string literal that bypasses the helper (lint or grep rule).
- [ ] Locale detection follows system settings; RTL layout tested with a pseudo-locale. (Locale detection, pseudo-locale, and RTL helpers are unit-tested; the visual RTL check needs the real UI.)

## Definition of done

- [ ] Tests added or updated; `cargo test` passes
- [ ] `cargo clippy -- -D warnings` and `cargo fmt --check` pass
- [ ] No user-facing string bypasses the i18n helpers
- [ ] Docs updated; screenshot attached for UI changes
